# Example Datasets

These small synthetic CSVs are designed for local demos and tests. They are intentionally tiny, GitHub-friendly, and include common tabular data issues such as missing values, duplicate rows, categorical fields, boolean fields, and ID-like columns.

## Regression

File: `regression_housing.csv`

Use this to demonstrate regression modeling.

- Target column: `sale_price`
- Includes numeric housing attributes, neighborhood categories, a boolean garage flag, missing values, one duplicate row, and an ID-like `home_id` column.

## Classification

File: `classification_churn.csv`

Use this to demonstrate binary classification.

- Target column: `churn`
- Includes customer tenure, monthly charges, contract type, support tickets, auto-pay status, missing values, one duplicate row, and an ID-like `customer_id` column.
